# Psycheval Documentation

Psycheval builds Agent evaluations on Harbor, keeps maintained Tasks in PBench,
and provides peval-py for trajectory inspection and comparison.

## Products

- [Psycheval](psycheval/README.md): install the Harbor extensions, run harnesses,
  and understand trusted-host execution.
- [PBench](pbench/README.md): run the maintained Agent capability Dataset and
  interpret its scoring.
- [peval-py](peval-py/README.md): convert sessions, build reports, and use the
  local Eval Workspace.
- [peval-py 简体中文](i18n/zh-CN/peval-py/README.md)

Stable contracts live in [`specs/`](../specs/README.md). These pages focus on
user workflows and link to the owning specification when exact behavior matters.
